# Bing Daily Wallpaper v1.4.6

## Release Title
Bing Daily Wallpaper v1.4.6 - Maintenance release

## Release Notes

This release has no functional changes. It exists so that the in-app updater of 1.4.5 has a newer version to install, which confirms the update of a system-wide Flatpak install through the password prompt.

### Versioning
- Centralized app version updated to `1.4.6`.
- EXE version resource regenerated via `generate_version_info.py`.
